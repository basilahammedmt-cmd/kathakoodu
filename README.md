# കഥക്കൂട്

നാലാം ക്ലാസ്സിലെ കുട്ടികളുടെ കഥയും കവിതയും ചിത്രവും ഫോട്ടോ എടുത്ത്, ടീച്ചർ ടൈപ്പ് ചെയ്തോ പറഞ്ഞോ എഴുത്താക്കി, സംസാരിക്കുന്ന ആനിമേഷനും മറിച്ചുനോക്കാവുന്ന പുസ്തകവും ആക്കുന്ന വെബ് ആപ്പ് (PWA). **ഒരു പൈസയും ചെലവില്ലാതെ പ്രവർത്തിക്കും.** ഒരേ ആപ്പ് ഫോണിലും കമ്പ്യൂട്ടറിലും പ്രവർത്തിക്കും; ഫോണിൽ ഹോം സ്ക്രീനിൽ ഇൻസ്റ്റാൾ ചെയ്യാം.

## ഘടന

| ഫയൽ | എന്ത് |
|---|---|
| `index.html`, `styles.css`, `app.js` | ആപ്പ് (build ഇല്ല, plain HTML/JS) |
| `manifest.webmanifest`, `sw.js`, `icons/` | ഫോണിൽ ഇൻസ്റ്റാൾ ചെയ്യാനും നെറ്റ് ഇല്ലാതെ തുറക്കാനും |
| `app.js` → രംഗ സഹായി | കുട്ടിയുടെ വാചകങ്ങൾ 4–6 രംഗങ്ങളാക്കി സ്ഥലവും പറയുന്നയാളെയും ഊഹിക്കുന്നു (AI ഇല്ല, ഫ്രീ) |
| `app.js` → വോയിസ് ബട്ടൺ | ബ്രൗസറിന്റെ മലയാളം speech recognition (`ml-IN`) വഴി പറഞ്ഞ് എഴുതൽ (ഫ്രീ) |
| `api/ocr.js` *(ഐച്ഛികം)* | ഫോട്ടോയിലെ മലയാളം കൈയക്ഷരം Claude വായിക്കുന്നു |
| `api/scenes.js` *(ഐച്ഛികം)* | എഴുത്തിനെ 4–6 രംഗങ്ങളാക്കുന്നു |
| `install.html` | ഡൗൺലോഡ്/ഇൻസ്റ്റാൾ പേജ് |
| `supabase/schema.sql` | Supabase-ലെ ടേബിളും ഫോട്ടോ ബക്കറ്റും സുരക്ഷാ നിയമങ്ങളും |
| `api/config.js` | Claude സജ്ജമാണോ, ക്ലാസ് കോഡ് വേണോ എന്ന് ആപ്പിനോട് പറയുന്നു |

ലോഗിൻ ചെയ്യാതെ ഉപയോഗിച്ചാൽ സൃഷ്ടികൾ ആ ഫോണിൽ മാത്രം. ടീച്ചർ ലോഗിൻ ചെയ്താൽ Supabase-ൽ സേവ് ആകും, ഏത് ഫോണിലും കമ്പ്യൂട്ടറിലും കാണാം. നെറ്റ് ഇല്ലാത്തപ്പോഴും ഫോണിൽ സേവ് ആകും; നെറ്റ് വന്നാൽ തനിയെ അപ്‌ലോഡ് ആകും.

**ഡൗൺലോഡ് ലിങ്ക്:** `https://kathakoodu.vercel.app/install` — ഇൻസ്റ്റാൾ ബട്ടൺ, Android/iPhone ഘട്ടങ്ങൾ, QR കോഡ്.

## Supabase (ടീച്ചർ ലോഗിൻ + ക്ലൗഡ് സേവ്)

1. supabase.com → **New project** (Region: **South Asia (Mumbai)**). ഡാറ്റാബേസ് പാസ്‌വേഡ് എവിടെയെങ്കിലും സൂക്ഷിക്കുക.
2. ഇടതുവശത്ത് **SQL Editor** → **New query** → `supabase/schema.sql` മുഴുവൻ ഒട്ടിച്ച് **Run**.
3. **Authentication → URL Configuration**:
   - Site URL: `https://kathakoodu.vercel.app`
   - Redirect URLs: `https://kathakoodu.vercel.app/**`
4. **Project Settings → API**-ൽ നിന്ന് രണ്ടെണ്ണം എടുക്കുക: **Project URL**, **anon public** key.
   `service_role` key ഒരിക്കലും എടുക്കരുത്, എവിടെയും ഇടരുത്.
5. Vercel → **Settings → Environment Variables**:

| പേര് | മൂല്യം |
|---|---|
| `SUPABASE_URL` | Project URL (ഉദാ: `https://abcd.supabase.co`) |
| `SUPABASE_ANON_KEY` | anon public key |

6. **Redeploy**. ഷെൽഫിൽ "ടീച്ചർ ലോഗിൻ" ബട്ടൺ വരും.

ഓരോ ടീച്ചറും "പുതിയ അക്കൗണ്ട്" വഴി ചേരും; ഇമെയിലിൽ വരുന്ന ലിങ്ക് അമർത്തി ഉറപ്പിക്കണം. ഒരു ടീച്ചറുടെ സൃഷ്ടികളും ഫോട്ടോകളും മറ്റാർക്കും കാണാനാവില്ല (Row Level Security). ലോഗൗട്ട് ചെയ്യുമ്പോൾ ആ ഫോണിൽ നിന്ന് ആ ടീച്ചറുടെ കോപ്പികൾ മായും.

Supabase-ന്റെ സൗജന്യ പ്ലാൻ: 500 MB ഡാറ്റാബേസ്, 1 GB ഫയൽ സ്റ്റോറേജ് (ഒരു ഫോട്ടോ ~300 KB → ഏകദേശം 3,000 ഫോട്ടോ). ഒരാഴ്ച ആരും ഉപയോഗിച്ചില്ലെങ്കിൽ സൗജന്യ പ്രോജക്റ്റ് "pause" ആകും; Supabase dashboard-ൽ Restore അമർത്തിയാൽ തിരിച്ചുവരും.

## Vercel-ൽ ഇടാൻ

1. vercel.com → **Add New → Project** → ഈ GitHub repo തിരഞ്ഞെടുക്കുക.
2. Framework Preset: **Other**. Build Command, Output Directory ശൂന്യമായി വിടുക.
3. ഇത്രയും മതി — ആപ്പ് ഫ്രീയായി പ്രവർത്തിക്കും.

### (ഐച്ഛികം) Claude ചേർക്കാൻ

പിന്നീട് ഫോട്ടോയിൽ നിന്ന് കൈയക്ഷരം വായിക്കാനോ Claude രംഗങ്ങൾ ഒരുക്കാനോ വേണമെങ്കിൽ മാത്രം (ഒരു സൃഷ്ടിക്ക് ഏകദേശം ₹3–4). key ഇല്ലെങ്കിൽ ഈ ബട്ടണുകൾ കാണിക്കില്ല.

**Settings → Environment Variables**-ൽ ചേർക്കുക:

| പേര് | മൂല്യം | വേണോ |
|---|---|---|
| `ANTHROPIC_API_KEY` | console.anthropic.com-ൽ നിന്നുള്ള key | Claude വേണമെങ്കിൽ |
| `CLASS_CODE` | ടീച്ചർമാർക്ക് മാത്രം അറിയാവുന്ന ഒരു കോഡ് | **ശക്തമായി ശുപാർശ** — ഇല്ലെങ്കിൽ ലിങ്ക് കിട്ടുന്ന ആർക്കും നിങ്ങളുടെ API key ചെലവിൽ Claude ഉപയോഗിക്കാം |
| `ANTHROPIC_MODEL` | ഉദാ: `claude-sonnet-5-5` | വേണ്ട (default ഇതാണ്) |

Environment Variables മാറ്റിയാൽ **Redeploy** ചെയ്യുക.

key-കൾ ഒരിക്കലും കോഡിലോ ചാറ്റിലോ ഇടരുത്; Vercel-ൽ മാത്രം.

## ഫോണിൽ ഇൻസ്റ്റാൾ ചെയ്യാൻ

- **Android:** Chrome-ൽ സൈറ്റ് തുറന്ന് ⋮ → *Install app* (അല്ലെങ്കിൽ ഷെൽഫിലെ "ഫോണിൽ ചേർക്കുക" ബട്ടൺ).
- **iPhone:** Safari-യിൽ തുറന്ന് Share → *Add to Home Screen*.

## വോയിസ് ബട്ടൺ

- Android-ലെ Chrome-ലും കമ്പ്യൂട്ടറിലെ Chrome/Edge-ലും പ്രവർത്തിക്കും. നെറ്റ് വേണം. ആദ്യം മൈക്കിന് അനുമതി ചോദിക്കും.
- iPhone-ലോ Firefox-ലോ മലയാളം കിട്ടിയില്ലെങ്കിൽ, കീബോർഡിലെ മൈക്ക് (Gboard → മലയാളം) ഉപയോഗിക്കാം; അതും ഫ്രീ.
- Chrome-ൽ ശബ്ദം Google-ന്റെ സെർവറിലാണ് എഴുത്താക്കുന്നത്. കുട്ടിയുടെയല്ല, ടീച്ചറുടെ ശബ്ദം ഉപയോഗിക്കുന്നതാണ് നല്ലത്.

## സ്വകാര്യത

- കുട്ടിയുടെ ആദ്യപേര് മാത്രം; രക്ഷിതാവിന്റെ സമ്മതപത്രം ഇല്ലാതെ സൃഷ്ടി ചേർക്കാനാവില്ല.
- കുട്ടിയുടെ മുഖമുള്ള ഫോട്ടോ ചേർക്കരുത്.
- Claude ചേർത്താൽ, ഫോട്ടോ അങ്ങോട്ട് അയക്കുന്നത് ടീച്ചർ ബട്ടൺ അമർത്തുമ്പോൾ മാത്രം.
