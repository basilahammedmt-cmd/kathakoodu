# കഥക്കൂട്

നാലാം ക്ലാസ്സിലെ കുട്ടികളുടെ കഥയും കവിതയും ചിത്രവും ഫോട്ടോ എടുത്ത്, Claude ഉപയോഗിച്ച് കൈയക്ഷരം വായിച്ച്, സംസാരിക്കുന്ന ആനിമേഷനും മറിച്ചുനോക്കാവുന്ന പുസ്തകവും ആക്കുന്ന വെബ് ആപ്പ് (PWA). ഒരേ ആപ്പ് ഫോണിലും കമ്പ്യൂട്ടറിലും പ്രവർത്തിക്കും; ഫോണിൽ ഹോം സ്ക്രീനിൽ ഇൻസ്റ്റാൾ ചെയ്യാം.

## ഘടന

| ഫയൽ | എന്ത് |
|---|---|
| `index.html`, `styles.css`, `app.js` | ആപ്പ് (build ഇല്ല, plain HTML/JS) |
| `manifest.webmanifest`, `sw.js`, `icons/` | ഫോണിൽ ഇൻസ്റ്റാൾ ചെയ്യാനും നെറ്റ് ഇല്ലാതെ തുറക്കാനും |
| `api/ocr.js` | ഫോട്ടോയിലെ മലയാളം കൈയക്ഷരം Claude വായിക്കുന്നു |
| `api/scenes.js` | എഴുത്തിനെ 4–6 രംഗങ്ങളാക്കുന്നു |
| `api/config.js` | Claude സജ്ജമാണോ, ക്ലാസ് കോഡ് വേണോ എന്ന് ആപ്പിനോട് പറയുന്നു |

ഇപ്പോൾ സൃഷ്ടികളും ഫോട്ടോകളും **അതേ ഫോണിൽ/ബ്രൗസറിൽ മാത്രം** (IndexedDB) സൂക്ഷിക്കുന്നു. ടീച്ചർ ലോഗിനും എല്ലാ ഉപകരണങ്ങളിലും കാണാവുന്ന ക്ലൗഡ് സേവും (Supabase) അടുത്ത ഘട്ടം.

## Vercel-ൽ ഇടാൻ

1. vercel.com → **Add New → Project** → ഈ GitHub repo തിരഞ്ഞെടുക്കുക.
2. Framework Preset: **Other**. Build Command, Output Directory ശൂന്യമായി വിടുക.
3. **Settings → Environment Variables**-ൽ ചേർക്കുക:

| പേര് | മൂല്യം | വേണോ |
|---|---|---|
| `ANTHROPIC_API_KEY` | console.anthropic.com-ൽ നിന്നുള്ള key | വേണം (ഇല്ലെങ്കിൽ ടൈപ്പ് ചെയ്യൽ മാത്രം) |
| `CLASS_CODE` | ടീച്ചർമാർക്ക് മാത്രം അറിയാവുന്ന ഒരു കോഡ് | **ശക്തമായി ശുപാർശ** — ഇല്ലെങ്കിൽ ലിങ്ക് കിട്ടുന്ന ആർക്കും നിങ്ങളുടെ API key ചെലവിൽ Claude ഉപയോഗിക്കാം |
| `ANTHROPIC_MODEL` | ഉദാ: `claude-sonnet-5-5` | വേണ്ട (default ഇതാണ്) |

4. Environment Variables മാറ്റിയാൽ **Redeploy** ചെയ്യുക.

key-കൾ ഒരിക്കലും കോഡിലോ ചാറ്റിലോ ഇടരുത്; Vercel-ൽ മാത്രം.

## ഫോണിൽ ഇൻസ്റ്റാൾ ചെയ്യാൻ

- **Android:** Chrome-ൽ സൈറ്റ് തുറന്ന് ⋮ → *Install app* (അല്ലെങ്കിൽ ഷെൽഫിലെ "ഫോണിൽ ചേർക്കുക" ബട്ടൺ).
- **iPhone:** Safari-യിൽ തുറന്ന് Share → *Add to Home Screen*.

## സ്വകാര്യത

- കുട്ടിയുടെ ആദ്യപേര് മാത്രം; രക്ഷിതാവിന്റെ സമ്മതപത്രം ഇല്ലാതെ സൃഷ്ടി ചേർക്കാനാവില്ല.
- കുട്ടിയുടെ മുഖമുള്ള ഫോട്ടോ ചേർക്കരുത്.
- ഫോട്ടോ Claude-ലേക്ക് അയക്കുന്നത് "കൈയക്ഷരം വായിക്കുക" അമർത്തുമ്പോൾ മാത്രം.

## ലോക്കലായി ഓടിക്കാൻ

```bash
npm i -g vercel
vercel dev
```
